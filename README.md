# bookMari
Fast, sleek, colourful bookmark manager with notes.

- apps/windows   - desktop app (Windows)
- apps/extension - Chrome/Edge/Brave + Firefox extension
- apps/android   - Android app
- packages/core  - shared logic: data model, search, import/export
- packages/ui    - shared design system + components
- packages/sync  - sync layer (later phase)
- docs           - plans, specs, design
